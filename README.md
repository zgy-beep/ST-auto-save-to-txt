# SillyTavern 小说连载阅读流 (Novel Stream)

> **让 AI 的每一轮回复，自然流淌成一本精彩的小说。**  
> 专为沉浸式故事阅读打造：告别冰冷生硬的技术日志，自动将你的角色扮演对话编排为规范、高雅的小说章节。

---

## 📖 核心体验

- **自动生成小说章节**：每次 AI 回复完成后，自动作为新章节续写进当前角色的专属小说（`<角色名>.txt`）。
- **手机阅读器自动识别目录**：默认采用 `第 X 节 · 角色名` 格式，导入**微信读书、掌阅、ReadEra、多看**等阅读器时，能**直接自动生成可点击的章节目录**，像看正版出版小说一样翻阅！
- **双重标签过滤引擎（白名单 + 黑名单）**：
  - **白名单（指定正文标签）**：若预设把小说正文固定写在 `<story>...</story>` 或 `<response>` 内，填入标签名即可精准提取正文，自动丢弃外部所有杂乱元数据。留空则整篇全保留。
  - **黑名单（排除标签块）**：在提取到的正文中，继续深度剔除内部的 `<status>`、`<memory>`、`<ooc>`、`<note>` 等干扰块。
  - **全自动思维链/前置无头标签过滤**：不仅覆盖各类思考模型（DeepSeek、Claude 等），还通用支持**任意自定义标签**（无论是反代、插件还是 Prefill 导致的开篇缺少开标签、仅有闭标签，如 `</think_fox~>`、`</analysis>`、`</scratchpad>` 等），均能全自动识别并完整切除前置非正文内容，绝不污染小说。
- **中文小说典雅排版**：自动支持段落首行全角双空格缩进（空两格），段落分明，排版优雅。
- **纯前端免配置导出**：面板内提供 **【📥 导出整本小说 TXT】**，即使没有安装或配置服务端插件，也能一键把全部对话按小说排版直接下载为 txt！
- **主角对白自由融入**：可选择纯小说故事流（仅记录 AI 故事），或将你（主角）的互动发言作为剧情对白无缝融入小说。
- **防重复连载**：滑动切换（Swipe）或重新生成时，自动识别并跳过相同内容，绝不产生重复废段。

## 🚀 极简安装步骤

### 第一步：在 SillyTavern 中安装扩展
1. 打开 SillyTavern，点击顶部栏的 **扩展菜单（三块方块/积木图标）**。
2. 点击 **“Install Extension”（安装扩展）**，输入仓库地址：
   ```text
   https://github.com/zgy-beep/ST-auto-save-to-txt
   ```
3. 安装完成后，刷新浏览器页面。

### 第二步：复制服务端连载插件（若需每轮自动后台落盘）
> 💡 *若仅使用纯前端一键导出功能，此步骤可跳过。*
1. 进入下载好的扩展目录：
   `SillyTavern/public/scripts/extensions/third-party/ST-auto-save-to-txt/plugins/auto-save`
2. 将 **`auto-save`** 文件夹复制到 SillyTavern 根目录的 **`plugins/`** 下：
   即目标路径为：`SillyTavern/plugins/auto-save/`
3. 打开 SillyTavern 根目录的 **`config.yaml`**，将 `enableServerPlugins` 改为 `true` 并重启酒馆服务。

## 🖥️ 小说连载设置

在 SillyTavern 顶部导航栏点击 **扩展图标（积木图标）**，展开 **【📖 小说连载阅读 (Novel Stream)】**：

- **开启小说自动连载**：开启后，每次 AI 回复自动续写。
- **章节目录风格**：
  - `第 X 节 · 角色名`（**强烈推荐**：手机阅读 APP 可自动生成目录树）。
  - `优雅分割线 (* * *)`（散文体，适合连续通读）。
  - `纯净戏剧体 (【角色名】)`（剧本体）。
- **指定正文标签（白名单，可选）**：
  - 留空代表整篇保留。
  - 若预设用 `<story>` 包裹正文，填入 `story`，系统只提取该标签内容。
- **排除的标签块（黑名单）**：
  - 默认包含：`status, memory, details, variables, analysis, ooc`。
  - 会彻底剔除这些标签块及其包裹的所有内容。
- **将你的发言作为主角对白融入小说**：根据你的阅读喜好勾选。
- **段落首行空两格**：符合中文出版排版规范。
- **📥 导出整本小说 TXT**：纯前端一键打包下载全部已聊内容，随时随地导出。
- **试写一章**：一键生成一段试读小说章节，验证连载与标签过滤是否正常。

## 📂 我的小说保存在哪里？

所有连载小说保存在 SillyTavern 服务端：
```text
SillyTavern/plugins/auto-save/logs/
├── 角色名A.txt
├── 角色名B.txt
└── 我的小说试读本.txt
```
