# SillyTavern 小说连载阅读流 (Novel Stream)

> **让 AI 的每一轮回复，自然流淌成一本精彩的小说。**  
> 专为沉浸式故事阅读打造：告别冰冷生硬的技术日志，自动将你的角色扮演对话编排为规范、高雅的小说章节。

---

## 📖 核心体验

- **自动生成小说章节**：每次 AI 回复完成后，自动作为新章节续写进当前角色的专属小说（`<角色名>.txt`）。
- **手机阅读器自动识别目录 & 原楼层精准溯源**：默认采用 `第 X 章 · 角色名 (原楼层: Y)` 格式，导入**微信读书、掌阅、ReadEra、多看**等阅读器时，能**直接自动生成可点击的章节目录**，同时标注酒馆对应楼层位置，排查漏网标签或回溯问题楼层极其方便！
- **自动添加 UTF-8 BOM 与《书名》扉页**：首次新建小说自动生成优雅的《书名》标题，并写入 UTF-8 BOM 标识，彻底杜绝部分旧设备、车载系统或老版 Windows 记事本打开时出现“锟斤拷”乱码。
- **智能适配“重新生成 (Regenerate)”与“滑动分支 (Swipe)”**：当你在酒馆中点击重新生成或划动分支时，插件会自动将小说末尾的该章节替换为最新生成的内容，绝不在小说里残留废弃的旧版本！
- **多角色群聊 (Group Chat) 自动聚合**：智能识别酒馆群聊环境，自动将群内所有角色的对话完整编排进同一本群小说（`[群聊] 群名称 - 对话名.txt`），绝不撕裂剧情。
- **双重标签过滤引擎（白名单 + 黑名单）**：
  - **白名单（指定正文标签）**：若预设把小说正文固定写在 `<story>...</story>` 或 `<response>` 内，填入标签名即可精准提取正文，自动丢弃外部所有杂乱元数据。留空则整篇全保留。
  - **黑名单（排除标签块）**：在提取到的正文中，继续深度剔除内部的 `<status>`、`<memory>`、`<ooc>`、`<note>` 等干扰块。
  - **全自动思维链/前置无头标签过滤**：不仅覆盖各类思考模型（DeepSeek、Claude 等），还通用支持**任意自定义标签**（无论是反代、插件还是 Prefill 导致的开篇缺少开标签、仅有闭标签，如 `</think_fox~>`、`</analysis>`、`</scratchpad>` 等），均能全自动识别并完整切除前置非正文内容。
  - **HTML 注释与图片表情清洗**：彻底滤除 `<!-- Lorebook: ... -->` 隐藏标注与 `![表情](url)`、`<img>` 网页代码，保持纯正纸质小说阅读质感。
- **未安装服务端自动防 404 保护**：若尚未配置服务端插件，扩展会自动**取消勾选连载开关**并拦截报错，彻底告别频繁的 HTTP 404 弹窗困扰。
- **动态自适应一键部署命令**：前端面板自动探测当前扩展安装路径（**完全杜绝写死文件夹名**），并提供 **Windows**、**Linux**、**Docker 容器（群晖/1Panel/NAS 等挂载环境）** 的自适应单行复制命令，终端粘贴即完成部署！
- **中文小说典雅排版**：自动支持段落首行全角双空格缩进（空两格），段落分明，排版优雅。
- **纯前端免配置一键导出（方案 C 推荐）**：即使完全不配置服务端插件、不碰任何终端命令，也能点击 **【📥 导出整本小说 TXT】**，直接在浏览器端将全量对话排版并下载为完整小说！
- **主角对白自由融入**：可选择纯小说故事流（仅记录 AI 故事），或将你（主角）的互动发言作为剧情对白无缝融入小说。
- **全方位连载状态与通知提醒**：
  - **屏幕 Toast 弹窗通知**：每轮 AI 回复排版写入完成时，屏幕右上角会弹出轻量通知（如 `《艾莉丝》第 12 节 · 艾莉丝 已自动写入`），更新进度一清二楚；如果不希望被打扰，也可以在面板中随时关闭弹窗。
  - **抽屉折叠栏动态指示灯**：抽屉即使在折叠收起状态下，顶栏也会实时显示 `连载更新中...` 或 `已更新 16:30`。
  - **面板内【最近连载动态】卡片**：清晰记录最新一节的更新时间、章节序号、角色名以及保存的具体文件路径，是否成功写入一目了然！
- **精准防重复写入机制**：重构末尾精确比对算法，绝不误伤前文出现的同名短句或口头禅，保障剧情 100% 完整收录。

## 🚀 极简安装步骤

### 第一步：在 SillyTavern 中安装扩展
1. 打开 SillyTavern，点击顶部栏的 **扩展菜单（三块方块/积木图标）**。
2. 点击 **“Install Extension”（安装扩展）**，输入仓库地址：
   ```text
   https://github.com/zgy-beep/ST-auto-save-to-txt
   ```
3. 安装完成后，刷新浏览器页面。

### 第二步：部署服务端插件（若需每轮自动后台落盘）
> 💡 *若仅使用纯前端一键导出功能，此步骤可完全跳过！*
1. 打开扩展设置抽屉，点击 **【复制命令】**（前端会根据您的操作系统与容器环境自动生成最精确的路径）。
2. 在终端（或 Docker 容器终端）粘贴执行该命令。
3. 确认 SillyTavern 根目录的 **`config.yaml`** 中 `enableServerPlugins: true` 并重启酒馆服务。

## 🖥️ 小说连载设置

在 SillyTavern 顶部导航栏点击 **扩展图标（积木图标）**，展开 **【📖 小说连载阅读 (Novel Stream)】**：

- **开启小说自动连载**：开启后，每次 AI 回复自动续写。
- **连载更新时弹出轻量提示通知（Toast）**：开启后，每当新章节写入完成时，屏幕右上角会弹出提示；如喜欢完全静默更新，可随手关闭。
- **章节目录风格**：
  - `第 X 章 · 角色名 (原楼层: Y)`（**默认推荐**：自动标注酒馆真实原始楼层，排查漏网标签或回溯剧情极其方便）。
  - `第 X 节 · 角色名`（纯净小说目录，无楼层标记）。
  - `优雅分割线 (* * *)`（散文体，适合连续通读）。
  - `纯净戏剧体 (【角色名】)`（剧本体）。
- **文件命名规则（多聊天/新开局防覆盖）**：
  - `角色名 - 对话名`（**默认推荐**）：开启新聊天或平行分支时，自动保存为全新独立小说（如 `艾莉丝 - 2026-09-10.txt` 或自定义对话名），**新旧对话彼此独立，绝不会相互覆盖或串台**！
  - `仅角色名`：所有聊天内容均归入同一本小说（如 `艾莉丝.txt`）。
- **指定正文标签（白名单，可选）**：
  - 留空代表整篇保留。
  - 若预设用 `<story>` 包裹正文，填入 `story`，系统只提取该标签内容。
- **排除的标签块（黑名单）**：
  - 默认包含：`status, memory, details, variables, analysis, ooc`。
  - 会彻底剔除这些标签块及其包裹的所有内容。
- **将你的发言作为主角对白融入小说**：根据你的阅读喜好勾选。
- **段落首行空两格**：符合中文出版排版规范。
- **指定保存文件夹（可选）**：
  - **留空**：默认保存在 `SillyTavern/plugins/auto-save/logs/`。
  - **自定义目录**：支持填写电脑上的任意文件夹绝对路径（例如 `D:\我的小说`、OneDrive/坚果云同步盘目录、NAS 挂载目录、Obsidian 库目录）或相对路径（如 `novels`），插件会自动创建对应目录并将小说写入其中！
- **📚 同步历史到连载文件（解决半路使用痛点）**：
  - 半路才启用插件？不用担心！点击此按钮，插件会自动从第 1 条消息开始，将之前全部历史对话一次性排版成小说写入到服务端文件；**后续 AI 新回复将自动无缝接着下一章继续往后连载**！
- **📥 导出整本小说 TXT**：纯前端一键打包下载全部已聊内容，随时随地导出。
- **试写一章**：一键生成一段试读小说章节，验证连载与标签过滤是否正常。

## 📂 我的小说保存在哪里？

- **默认存储路径**：
  ```text
  SillyTavern/plugins/auto-save/logs/
  ├── 角色名A.txt
  ├── 角色名B.txt
  └── 我的小说试读本.txt
  ```
- **自定义路径**：若在设置面板填写了“指定保存文件夹”，所有角色小说将实时保存在您指定的文件夹中。
