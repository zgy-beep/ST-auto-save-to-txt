## 能帮你做什么

- **自动成书**：每轮 AI 回复自动编排成「第 X 章」，追加写入 TXT 小说文件，随时追更。
- **阅读器友好**：生成的 TXT 带目录结构，导入微信读书、ReadEra、掌阅、多看等 App 后自动识别章节、可点目录跳转，进度还能云同步与听书。
- **干净正文**：自动剔除状态栏、思考过程、OOC 闲聊、变量面板等干扰内容，只留下小说正文。
- **重 roll 不留废案**：重新生成或划动分支时，小说末尾对应章节会替换成最新版本，不留废弃剧情。
- **图文并茂**：如果你用图像生成扩展给回复配了插画，还能导出带插图的 EPUB 电子书，图片按正文原位插入；既可以保存到服务端，也可以直接下载到本机。
- **不装服务端也能用**：不想折腾后台？纯前端一键导出整本 TXT，聊完随时下载。

## 快速上手

两种用法，按需选择：

| 用法 | 适合谁 | 怎么做 |
| :--- | :--- | :--- |
| **A. 纯前端导出** | 只想聊完导出、不想装后台的用户 | 装好扩展 → 正常聊 → 点【导出整本 TXT】 |
| **B. 后台自动连载** | 想每轮自动续写、用 NAS/网盘同步追更的用户 | 额外部署一次服务端插件 → 打开「自动连载」开关 |

> 两种可以同时用：开着自动连载，也随时能一键导出备份。

## 安装

### 第一步：安装扩展（必做）

1. 打开 SillyTavern，点顶部栏的**扩展管理图标**（积木图标）。
2. 点 **Install Extension**，粘贴本仓库地址：

   ```text
   https://github.com/zgy-beep/novel-stream
   ```

3. 安装完成后**刷新网页**。
4. 刷新后，聊天输入框左下角的 **魔法棒** 菜单里会出现 **「小说连载阅读」**；屏幕右下角也会出现一枚小说入口小圆钮。点任意一个即可打开设置面板。

> **找不到设置面板？** 它**不在「扩展程序」抽屉里**，请从 魔法棒菜单或右下角小圆钮进入。

**只想要用法 A（纯前端导出）的话，到这里就完成了。**

### 第二步：部署服务端插件（仅用法 B 需要）

<details open>
<summary><b>一键部署（推荐）</b></summary>

打开终端（本机或服务器），按系统复制对应命令执行：

**Windows**（PowerShell 中执行）：

```powershell
irm https://cdn.jsdelivr.net/gh/zgy-beep/novel-stream@main/install.ps1 | iex
```

**Linux / VPS / 群晖 NAS / Docker 宿主机**（SSH 中执行）：

```bash
curl -fsSL https://cdn.jsdelivr.net/gh/zgy-beep/novel-stream@main/install.sh | bash
```

脚本会自动寻找正在运行的酒馆、识别 Docker 容器并完成部署，不需要手动找路径。

</details>

<details>
<summary><b>手动复制（离线环境）</b></summary>

1. 找到刚安装的扩展目录，通常在：
   `SillyTavern/data/default-user/extensions/novel-stream/`
   （旧版本可能是 `SillyTavern/public/scripts/extensions/third-party/novel-stream/`）
2. 把其中的 `plugins/auto-save` 整个文件夹复制到 **酒馆根目录的 `plugins/`** 下。
   （扩展文件夹名取决于安装来源，以你实际看到的文件夹名为准，关键是其中的 `plugins/auto-save`。）
3. 确认最终存在 `SillyTavern/plugins/auto-save/index.js`。

</details>

<details>
<summary><b>启用服务端插件并重启酒馆</b></summary>

1. 用文本编辑器打开酒馆根目录的 `config.yaml`。
2. 找到 `enableServerPlugins`，把它改成 `true`：

   ```yaml
   enableServerPlugins: true
   ```

3. **彻底重启酒馆**：关掉运行酒馆的命令行窗口，重新启动（只刷新网页无效）。
4. 刷新网页，打开设置面板勾选 **「开启小说自动连载」**，指示灯变绿即可。

</details>

### 更新扩展后请重新部署服务端插件

酒馆的扩展更新器**只更新扩展本身**，不会同步酒馆根目录下的 `plugins/auto-save`。所以更新扩展后请：

1. 重新执行一次上面的一键部署命令（或手动覆盖 `plugins/auto-save`）；
2. 确认 `config.yaml` 中 `enableServerPlugins: true`；
3. **彻底重启酒馆**。

否则可能出现「提示未检测到服务端插件」或新功能不生效。

## 使用指南

### 打开设置面板

点 **魔法棒 → 「小说连载阅读」**，或点右下角小圆钮。面板分 **连载 / 过滤 / 排版 / 文件 / 通用** 五个标签，分组默认收起，点标题展开。

### 开启自动连载

设置面板顶部的 **「开启小说自动连载」** 是总开关。勾选后，每轮 AI 回复都会自动写入小说。

- 若未部署服务端插件，插件会自动取消勾选并提示，避免反复报错。
- 每章写入成功时会弹一条轻提示（可在设置里关闭）。

### 章节样式与文件命名

- **章节样式**（推荐默认样式）：
  - `第 X 章 · 角色名 (原楼层: Y)` —— 阅读器识别目录最稳，同时标明来自哪层楼，方便回溯。
  - `第 X 节 · 角色名` —— 不显示楼层。
  - `优雅分割线 (* * *)` —— 散文体，章节间用星号分隔。
  - `纯净戏剧体 (【角色名】)` —— 剧本体，适合对话密集的剧情。
- **文件命名**：
  - `角色名 - 对话名`（推荐）：每个聊天一个独立文件，新开平行世界也不会串台。
  - `仅角色名`：该角色所有对话都写进同一本书。
  - 多用户模式下会自动加账号前缀，避免不同账号互相覆盖。

### 过滤掉不需要的内容

预设里的状态栏 `<status>`、思考过程 `<think>`、OOC 闲聊等会混进正文。两种过滤方式：

- **白名单**：如果预设把正文包在固定标签里（如 `<story>…</story>`），填 `story` 就只提取标签内的内容。**不确定就留空**——留空表示整篇保留。
- **黑名单**：要剔除的标签，逗号分隔。默认已包含 `status,memory,details,variables,analysis,ooc,note,draft,system,log`。

**免手打**：面板里的「会话标签检测」会自动列出当前聊天里出现过的标签，点「白」/「黑」即可加入名单，鼠标悬停可预览标签内容。

**改完别急着存**：点【查看过滤效果预览】，弹窗会左右对比「入书正文 vs 原始回复」，并用红色标出被剔除的内容，一眼就能确认配置对不对。

### 导出、同步与试写

设置面板【文件】标签里：

- **【导出整本 TXT】**：纯前端生成，不依赖服务端，随时可用，没有体积限制。
- **【同步历史连载】**：聊到一半才装插件？点它把之前的全部聊天记录一次性整理成书，之后的新回复接着写。
- **【试写一章】**：写入一章测试内容，确认服务端是否正常。

### 其他实用选项

- **段落首行空两格**：默认开启，符合中文小说排版习惯。
- **把你的发言也写进小说**：默认关闭。开启后你说的每句话也会编排进书。
- **草稿缓冲**：默认关闭。开启后最新一楼的回复先不写，等你发下一条消息才定稿——适合边 Roll 边改。
- **右下角悬浮入口**：默认开启，可拖动到任意位置并被记住；不需要可在设置里关掉。
- **聊天改名自动跟随**：聊天标题改名后，已经写好的小说文件会一起改名，不会出现两份。

## 图片电子书（EPUB）

如果你用 bbi 等图像生成扩展给每轮回复配了插画，可以导出**带插图的 EPUB 电子书**，图片会按它在正文中的位置插入，导入微信读书 / ReadEra / 掌阅即可图文并茂地阅读。

### 使用条件

- 需要部署**服务端插件**（图片读取与 EPUB 打包都在服务端完成，再由浏览器下载或写入服务器目录）。
- 「嵌入插画」需要服务端插件 1.14.0+；「下载到本机」需要服务端插件 1.15.0+；「导出前体积预估提示」需要服务端插件 1.16.0+。版本过旧时对应按钮会置灰并提示你更新（旧版插件仍可导出，只是没有体积预估）。

### 操作步骤

1. 打开设置面板 →【文件】标签 → 展开 **「图片电子书（EPUB）」**。
2. 按需勾选 **「导出时嵌入图片」**（默认关闭）：勾选后才会读取 bbi 等扩展生成的插画，并按正文原位嵌进 EPUB。
   - **不勾选**：导出纯文字 EPUB，只含整理好的正文；TXT 自动连载与【导出整本 TXT】完全不受影响。
3. 点 **【图片清单预览】** 先看一眼：识别到几张图、有没有缺图、有没有位置不确定的。**建议先看再导。**
4. 选一种导出方式（导出前会先预估电子书体积）：
   - **【导出到服务器】**：EPUB 写入服务端的保存目录（与小说 TXT 同目录，可在上方「保存位置」里修改）。
   - **【下载到本机】**：浏览器直接把 EPUB 下载到本机，不写入服务器，也不需要配置保存目录。
5. 用手机阅读器导入 `.epub` 即可。

### 几点说明

- **开关只管 EPUB**：勾不勾选都不会影响 TXT 连载；不勾选时导出的就是纯文字电子书。
- **位置**：图片会落在它原本对应的那一段文字附近；如果某条消息里图片和正文位置对不上，插件会把该消息的图统一放到章尾，并在预览里说明——**不会乱猜位置，也不会丢图**。
- **缺图**：图片文件找不到或超过大小上限时，会跳过并在结果里列出，不会影响整本书导出。
- **格式**：建议用 PNG / JPEG。部分老阅读器不支持 WebP，插件不会自动转换格式。
- **体积**：默认单张上限 5MB、全书上限 80MB，可在设置里调整；下载到本机同样受这些上限约束。
- **体积提示**：导出前会先预估电子书体积（「图片清单预览」里也会显示）。图片总量超过「图片总量上限」时会提示并支持**一键把上限调高后继续**；预计超过 **100MB** 时会二次确认，提醒大电子书在部分手机阅读器上导入可能变慢或失败。实测图片很多（如 130MB+）时请留意该提示。
- **Docker / NAS 用户**：若自动找不到图片，可在设置里填写酒馆根目录（如 `/home/node/app`）。

## 在手机上阅读

生成的 TXT 自带《书名》扉页、目录章节与 UTF-8 BOM 编码，主流阅读器都能直接识别：

1. **微信读书**：书架右上角【+】→【从本地导入】→ 选择 TXT/EPUB。目录自动生成，支持进度云同步与听书。
2. **ReadEra**（安卓）：把文件放进手机目录或网盘同步文件夹，ReadEra 会自动扫描，目录树清晰无广告。
3. **掌阅 / 多看 / 苹果图书**：直接导入即可，不会出现乱码。

> 想让目录更稳？保持默认的「第 X 章 · 角色名 (原楼层: Y)」样式即可。

## 遇到问题怎么办

### 提示「未检测到服务端插件 (HTTP 404)」

说明酒馆后端没有找到插件。按顺序检查：

1. 是否存在 `SillyTavern/plugins/auto-save/index.js`（没有就重新部署）；
2. `config.yaml` 中 `enableServerPlugins` 是否为 `true`；
3. 是否**彻底重启**过酒馆（只刷新网页无效）；
4. 扩展更新过？请按上面「更新扩展后请重新部署服务端插件」重做一遍。

不想折腾服务端也没关系：直接用【导出整本 TXT】即可。

### 「导出时嵌入图片」勾不上 / 点了没变化

这是 **v1.17.9 及更早前端**的已知症状：旧版这个开关没有样式，面板又把浏览器原生勾选标记隐藏了——点击其实已经生效并保存，但**外观完全不变**，看起来就是“勾不上”。v1.18.0 起已改为可见的胶囊开关；v1.19.1 起还按控件 ID 加了兜底样式，**即使浏览器缓存了旧文件，也不会再出现“看不见勾选态”**。

如果更新后仍遇到，按顺序排查：

1. 看设置弹窗标题右侧的版本号，应为 **v1.19.1**；显示旧版本说明扩展文件没更新成功或被缓存；
2. 在酒馆「扩展管理」里对该扩展点 Update / 重新安装，确认 `index.js`、`style.css`、`manifest.json` **三个文件一起更新**（只换其中一个可能出现新旧混搭）；
3. 强制刷新页面（电脑 `Ctrl+F5`；手机清缓存或重开 App），必要时重启酒馆；
4. 仍异常请按 `F12` 打开浏览器控制台，把红色报错连同酒馆版本一起反馈。

### 提示「替换被拒绝 / 已放弃替换」

说明要替换的那一章不是文件里的最后一章（常见于你编辑过较早楼层、切换过章节样式、或手动改过 TXT）。处理办法：

点 **【同步历史连载】** 按当前聊天重新排一遍，再重新生成即可。**不要手动去删 TXT 里的章节**，那会让章节号更乱。

### 提示「写入文件失败」

界面只会显示这一句，具体原因需要看**酒馆服务端的命令行窗口**：

- 权限不足（Linux/Docker）：给目标目录写权限，如 `chmod -R 777 plugins/auto-save`；
- 文件被占用（Windows）：关掉正在打开该 TXT 的编辑器；
- 磁盘满了：清理空间。

### 提示「单章节篇幅过大」

某一楼回复太长（超过约 3.4 万字）被拦截，通常是 AI 陷入重复输出。在酒馆里重新生成或截断该回复即可。

### 提示「无法直接访问您本地电脑的盘符路径」

酒馆跑在云端/Docker，但你在「保存文件夹」里填了 `D:\...`。把该输入框**清空**（用默认目录），或填写服务器内的真实路径。

### 网络异常 / Failed to fetch

酒馆后端进程可能已经崩溃，或反向代理没有放行 `/api/` 路径。检查酒馆命令行窗口是否还在运行；用 Nginx / Cloudflare 反代的请确认代理了 `/api/`。

## 常见疑问

**Q：为什么新开聊天还没生成 TXT？**
这是有意设计的「延迟成书」：新开聊天只看看角色卡或调预设时，不会产生一堆空文件。等你发出第一句话正式开始时，角色的问候语会作为第 1 章补写进去。如果你是聊了几句才装插件，点【同步历史连载】补齐即可。

**Q：重新生成 / 划动分支后，旧剧情会留在小说里吗？**
只要重写的正是「最近一次写入的那一楼」，就会自动替换成新版本；如果替换目标不是最后一章，插件会拒绝替换并保留原文件，避免误删后面的章节。编辑较早楼层不会自动回改，请用【同步历史连载】重排。

**Q：提示「内容与前文重复，已略过」，是不是漏存了？**
不是，这是防重复写入的保护。网络波动或重复触发时，插件会发现末尾已有相同章节并跳过，避免同一章写两遍。

**Q：能把我的发言也写进小说吗？**
可以，在设置里勾选「将你的发言作为主角对白融入小说」。

**Q：删除楼层会不会把小说也删掉？**
不会自动删章节，但删除楼层后约 1.5 秒，插件会按**当前聊天**重新编排整本书并覆盖文件——聊天里已经不存在的内容会从 TXT 消失，你手动润色过的内容也会消失（覆盖前会留一份 `.bak` 备份）。
所以：**不要手动编辑正在连载的 TXT**；要长期保存请先用【导出整本 TXT】另存一份。

**Q：草稿缓冲是什么？**
开启后最新一楼先当草稿不写入，等你发下一条消息才定稿。适合边 Roll 边改；注意刷新页面前未定稿的那一楼不会保存。

**Q：改了过滤设置后章节号乱了？**
章节号按当前聊天实时计算，与文件里的历史编号可能错位。点一次【同步历史连载】即可对齐。

**Q：微信读书里目录出不来？**
保持默认章节样式「第 X 章 · 角色名 (原楼层: Y)」即可；文件已带 UTF-8 BOM，不会乱码。

## 给开发者：UI 规范与组件复用

本扩展的浮动 UI（弹窗 / 悬浮入口 / 折叠分组 / 胶囊开关 / 提示层等）已整理成一套 **独立项目** 的 UI Kit 规范，位于 [`ui-kit/`](ui-kit/README.md)。该目录自带 `package.json` / `LICENSE` / `CHANGELOG.md` / `test/`，**不依赖本仓库的任何其它文件，可整目录复制或移出到任意插件/仓库**：

- [ui-kit/README.md](ui-kit/README.md)：配色语义、设计令牌、组件 DOM 与状态、SillyTavern 宿主兼容红线（top-layer 载体、checkbox 样式隔离等）、命名约定与迁移对照；
- [ui-kit/tokens.css](ui-kit/tokens.css) / [ui-kit/components.css](ui-kit/components.css)：零依赖、`@import` 两个文件即可使用，支持深/浅主题；
- [ui-kit/preview.html](ui-kit/preview.html)：离线组件预览页，双击即可看全部组件与配色；
- [ui-kit/test/test-ui-kit.js](ui-kit/test/test-ui-kit.js)：项目内自带的规范守护测试（token 完整 / 三方覆盖 / 无硬编码颜色 / WCAG 对比度 / 宿主兼容红线 / 金标准取值），在 `ui-kit/` 目录下执行 `npm test` 即可独立运行；
- [ui-kit/CHANGELOG.md](ui-kit/CHANGELOG.md)：UI Kit 独立版本历史（当前 v1.1.0，与扩展版本互不影响）。

> 提示：UI Kit 是独立项目。如果你把 `ui-kit/` 移动到别处，本仓库的构建/测试不受影响（根测试套件不再包含它），后续请以该独立目录内的 `README.md` / `CHANGELOG.md` 为准。
