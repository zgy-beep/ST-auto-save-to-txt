UI Kit v1.0.0

SillyTavern 插件通用浮动 UI 组件与配色规范。只依赖 tokens.css 与 components.css，可整目录复制到下一个插件复用。规范文档见 README.md。

1. 配色令牌

组件样式禁止硬编码颜色，一律引用右侧 token。语义色只表达语义，不拿主色表达错误。

2. 文字层级

正文/次要/提示三档灰 + 字号刻度；正文层级不要超过两级混用。

标题级：--nvui-fs-2xl + 粗体
正文：这是正文文字 --nvui-text / --nvui-fs-md
次要：这是次要说明 --nvui-text-2，用于解释与补充
提示：这是提示性小字 --nvui-text-3，仅装饰与非关键信息
说明小字：.nvui-hint，用于设置项解释。
3. 按钮

默认中性、主操作用 is-primary（每屏建议最多 1 个）、次级 is-secondary、弱操作 is-ghost、破坏性 is-danger。

4. 胶囊开关行

含酒馆宿主 checkbox 样式隔离：清掉宿主的 ::before 对勾，开关状态由轨道颜色 + 滑钮位移表达。整行 label 可点。

开关状态会同步到这条说明文字（业务里一般同步到设置摘要）。
5. 输入行

左标题 + 右控件；数值框定宽右对齐，路径框定宽且窄屏不超过 60%。

6. 标签页

nav[role=tablist] + button[role=tab] + 面板 [role=tabpanel]；键盘左右切换与 Esc 由业务 JS 处理。

面板一：只切 display，不重建 DOM（避免丢输入焦点与异步结果）。
面板二：切换标签时建议把滚动位置复位。
面板三：内容可以继续嵌套折叠分组。
7. 折叠面板

收起态右侧摘要必须给「当前值」，否则折叠等于把设置藏起来；展开动画只改 class，不重建 DOM。

展开体里可以放说明、开关行、输入行与按钮组。
收起时用户只能看到右侧摘要，因此每个分组都必须维护摘要。
8. 提示、告警与状态行

告警用左侧竖线表达语义（不铺满底色）；状态行颜色即状态，时间戳贴右。

12. 布局工具

优先用 .nvui-stack / .nvui-row / .nvui-divider 组织间距，避免在模板里写内联 flex（便于主题与响应式统一）。

竖向堆叠.nvui-stack（gap = space-3）示例
两端对齐.nvui-row.is-between
--nvui-accent 行内代码 .nvui-code；文字色工具类： muted-2 accent-text ok-text warn-text danger-text info-text
读屏专用隐藏文本： 视觉上不可见（这段文字只会被读屏器朗读），但可被辅助技术读取。
13. 弹窗与 top-layer 载体

真实插件中必须把弹窗挂进 dialog.nvui-tl 并用非模态 show() 提升层级（避免酒馆 html transform 把 fixed 浮层顶出屏幕，也避免 showModal 的 inert 让其它入口点不到）。

弹窗内含：头部（标题 + 版本 + 关闭按钮）、正文、底部操作区；点遮罩或按 Esc 关闭。
